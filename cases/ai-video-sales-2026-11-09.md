# 案例：AI 广告视频服务找不到客户（2026-11-09）

> 历史样例，仅用于复盘当时的推理。不是规范、当前市场证据或可直接迁移的方案；使用前必须重新核验场景、数据、合规与时间条件。

## 输入事实

- 产品：AI 制作电商广告视频，自评"效果还可以"
- 渠道：旺旺私聊淘宝商家客服
- 提案：分成 / 按效果付费
- 结果：全部"不用了谢谢"
- 案例：只有 demo，无任何真实商家使用记录

## L1 结论卡

- **停滞类型**：客户定义与通道错配（主）＋ 证据缺失（次）
- **最窄瓶颈**：你在跟"没有决策权、且每天被推销轰炸"的岗位谈一个"需要最高信任的合作方式"
- **今天做什么**：把 1 条 demo 改成"针对某个具体店铺的改造对比片"，直接发给能拍板的人，话术里写"不用回复"
- **成熟度**：85/100（短板：证据强度 3/5，零真实商家数据）

**一句话**：**"不用了谢谢"不是对你视频的评价，是对这次对话的评价。** 你从未拿到过一次真正的评估，所以手上这些反馈里没有一个字是关于产品的。

## 三重错配

| 维度 | 你做的 | 应该是 |
| --- | --- | --- |
| 对象 | 店铺客服（无决策权、KPI 是响应速度） | 店长 / 运营 / 老板 / 同行工作室 |
| 结构 | 分成（需合同、归因、结算、信任） | 先给成品（零决策成本） |
| 证据 | 通用 demo | 同品类具体店铺的改造对比 |

## 为什么"分成"在冷启动必然失败

分成成立需要三个前提，你现在一个都没有：

1. **可归因**：视频带来的销量怎么算？商家不信你的归因。
2. **可信任**：一个没见过面的陌生人要分我的销售额，风险高于收益。
3. **值得麻烦**：单条视频成本几百元，走分成要签协议、对账、月结——麻烦程度超过金额。

结论：**分成是规模做起来之后的筹码，不是冷启动的工具。冷启动只能用"先给"换"一次试用"。**

## 一个必须纠正的自评

"视频效果还可以"目前是 ASSUMPTION，不是 FACT——因为没有一条真实商家的使用数据。
按证据规则：自评不能作为对外陈述，也不能作为你调整方向的依据。**你现在的所有判断，都建立在"我觉得好"上。**

## 换人：五个入口，按优先级

| 优先 | 入口 | 为什么 |
| --- | --- | --- |
| 1 | 电商摄影 / 美工工作室 | 他们常被问"能不能做视频"但不会 AI，你补的是产能，不需要被说服 |
| 2 | 电商代运营 / 服务商 | B 端会正常评估供应商，一次谈成可复用到多个客户 |
| 3 | 1688 源头工厂 / 批发商 | 需要给下游分销商提供素材，批量化需求 |
| 4 | 直播基地 / 电商产业园 | 一次能见到多个老板，效率最高 |
| 5 | 具体店铺的老板（企查查 / 店铺资质 / 逛逛运营） | 能找到人，但单个沟通成本高 |

**不要**再通过"联系客服"进入——那不是通道，是防推销的前线。

## 换话术：从"求合作"改成"先给"

```
我看了你们主图第 3 个视频，前 3 秒是静态图，完播率应该不高。
我用 AI 重做了一版（30 秒），已经放这儿：<链接>
不用回复，觉得能用直接拿去用，不能用就当我练手。
如果用了有效果，再聊后面怎么长期做。
```

三个要点，缺一不可：

1. **指出具体问题**——证明你真的看过，不是一个群发话术。
2. **先给成品**——对方的决策成本是零，所以没有理由说"不用了谢谢"。
3. **明确不用回复**——解除心理压力，这句话是把"推销"变成"赠品"的开关。

## 一周验证（不许中途改）

| 动作 | 数量 | 判据 |
| --- | --- | --- |
| 做针对性对比片 | 5 条 | 每条对应一个真实店铺的真实问题 |
| 发给能拍板的人 | 5 位（店铺老板 3 + 工作室 2） | 记录回复率与原话 |
| 免费试用 | 争取 2 个 | 有人真的把视频挂上去 |

**翻转条件**：若 5 条里有 ≥3 条被回复且 ≥1 个真的用了 → 问题确实是渠道，继续放量。
若 5 条针对性作品仍全部被当推销 → 改判为"需求不成立或品类选错"，换品类（服装/家居/食品三类目的素材需求差异极大），而不是继续加量。

**止损**：两周内 0 个真实使用 → 停止陌拜，转 B 端供片（工作室 / 代运营），用别人的客户关系换你的产能输出。

## 评分为何不高

杠杆率 4/5、可证伪 5/5 都不错，卡在证据强度 3/5：**你还没有一条"用了之后怎么样"的记录。** 补上这一条，整个生意的说服结构会变——从"我能做视频"变成"我让某店的主图视频完播率从 X 到 Y"。
