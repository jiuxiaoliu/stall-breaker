# 方案比较、红队与迭代

本文件只在存在多个真实选项、决策影响较大，或需要多轮收敛时读取。简单可逆问题不要为了形式而打分。

## 一、先过硬约束

任何方案命中以下条件即淘汰或暂停，不进入加权评分：违法、不安全或超出授权；超过可承受损失；错过真实时间窗口；依赖明确不存在的资源；违反用户明确的反目标；无法说明作用机制且无法低成本验证。

## 二、选择相关维度

从以下维度中选 5–8 个真正会改变本题选择的维度，不必全部使用：

| 维度 | 核心问题 |
| --- | --- |
| 问题命中 | 是否作用于主导断点，而非症状？ |
| 证据强度 | 关键假设有何证据，适用性如何？ |
| 机制清晰 | 动作如何经中间变量影响结果？ |
| 可行性 | 资源、能力、权限、时间是否具备？ |
| 时间匹配 | 何时产生领先信号和最终结果？ |
| 下行保护 | 最坏损失是否有上限？ |
| 可逆性/选择权 | 失败能否退出，是否锁死后续？ |
| 信息价值 | 即使失败，能否改善下一次决策？ |
| 利益相关者 | 谁会支持、抵消或否决？ |
| 复利与资产 | 重复后积累的是资产还是负担？ |

先记录用户偏好和硬约束，再定权重。不要沿用固定权重假装普适。

## 三、定性比较优先

普通决策使用“高/中/低 + 一句依据”。只有选项至少两个且机制不同、维度含义和权重已明确、数字确实有助于暴露权衡时才使用 1–5 分。

`总分 = Σ(维度权重 × 该维得分 / 5)`

规则：每个分数必须有事实或假设依据；分差小于评分误差时视为并列，改用最便宜实验区分；不强制某维低分或固定分差；新证据未改变维度或排序时不因措辞变好而加分；分数不是概率。

## 四、红队检查

对排名第一的方案检查：

1. 哪条单点假设失败会让方案整体失效？
2. 相同现象还可能由什么造成？
3. 谁有能力且有动机阻止它？
4. 短期收益会不会制造长期成本，反之亦然？
5. 资源减半或时间缩短时，核心机制是否仍成立？

红队后可以降分、维持或升分，关键是记录原因和修订，不强迫分数下降。

## 五、信息价值与下一轮

`信息价值 ≈ 改变决策的可能性 × 决策影响 ÷ 获取成本`

不必计算精确数值，只比较：知道答案后排序会变吗；错判代价大吗；获取它比直接小试更便宜吗。答案不会改变行动的信息暂时不查。

## 六、预注册翻转条件

```text
当前判断：
观察窗口：
若出现：
则改为：
最大可承受损失：
复核日期/节点：
```

窗口到期后可以基于新事实调整规则，但保留原判断，避免事后改写标准。

## 七、收敛节奏

- 可逆、低损失：尽快试，通常一轮足够；
- 中等影响：先区分主导假设，再试点；
- 不可逆、高影响：补关键证据、做独立复核、明确止损后再决定。

命中任一条件就停止继续分析：已有方案明显更优且下行可承受；新信息不再改变排序；最便宜的下一步是行动；证据不可得、无权限或窗口已过；成功标准或风险偏好仍无法确定，继续只会制造假精确。

停止时交付：已知、未知、当前选择、为什么现在停、何时复核。
