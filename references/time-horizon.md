# 多时间尺度决策

本文件用于避免两个常见错误：用短期止痛冒充长期最优，或用长期愿景逃避当前生存与验证。

## 一、按反馈周期定时间层

“短期、中期、长期”不是固定日历。先识别领域的自然反馈周期，再映射：

- **眼前**：0–1 个反馈周期，止损、解锁或取得关键事实；
- **近期**：1–3 个周期，验证主要机制；
- **中期**：3–12 个周期，形成可复用能力、资产、关系或流程；
- **长期**：超过 12 个周期，检查复利、路径依赖、结构变化和退出选项。

紧急事件可以用小时，产品验证可以用周，组织变化可能用季度。不要拿统一的“48 小时/2 周”替代领域节奏。

## 二、四层检查

| 层次 | 必答问题 | 典型风险 |
| --- | --- | --- |
| 眼前生存 | 什么损失必须先停止？什么窗口即将关闭？ | 为追求完美错过窗口 |
| 近期学习 | 哪个实验最能区分主要假设？ | 动作很多但信息增益低 |
| 中期积累 | 本轮行动会留下什么可复用资产？ | 永远靠一次性救火 |
| 长期选择 | 会锁定什么、依赖什么、放弃什么？ | 小胜累积成错误路径 |

## 三、跨期冲突

对每个方案检查：

1. 是否透支信誉、现金、健康、团队或客户关系来救眼前？
2. 是否以长期潜力为由忽视现金流、合法性或验证？
3. 是否优化局部指标却损害系统结果？
4. 是否过早形成平台、团队、合同、技术或身份依赖？
5. 失败后是否仍保留资金、时间、关系、数据和退路？
6. 重复执行后，积累的是资产还是债务？

## 四、情景推演

只推演会改变决策的少量情景，通常三个足够：基准情景、下行情景、上行情景。每个情景记录触发信号、影响、预先动作和可回退点。没有数据时使用范围或高/中/低，不编造精确概率。

## 五、跨期方案表

```text
方案：
眼前：解除什么阻塞 / 最大损失
近期：验证什么 / 观察窗口
中期：积累什么能力或资产
长期：路径依赖、复利与退出选择
下行情景：最早预警与止损
翻转条件：何时改选哪个备选
```

## 六、选择规则

优先选择同时满足以下条件的方案：不突破眼前生存与硬约束；近期获得高价值信息；失败也留下可复用资产或认知；不过早锁死长期路径；成功可放大，失败可退出。

若这些条件互相冲突，明确写出牺牲了什么，不把权衡伪装成双赢。
